# Documentation media

The main demo is a complete 160-second Stage-D match. It starts at zero,
finishes at 201, uses the exact 456-FUEL field, and combines a slanted field
view with three robot-camera insets and live telemetry.

https://github.com/user-attachments/assets/518c0220-82ed-45f1-b8d7-8007a5b0ea4c

Supporting public files:

- [`f4-interp-3202000-seed9211-score201-full-match-preview.mp4`](f4-interp-3202000-seed9211-score201-full-match-preview.mp4) — browser-ready H.264 video.
- [`f4-interp-3202000-seed9211-score201-poster.png`](f4-interp-3202000-seed9211-score201-poster.png) — static poster.
- [`score201-public-provenance.json`](score201-public-provenance.json) — sanitized match, checkpoint, and media checksums.

See the [video workflow](../VIDEO_RENDER_WORKFLOW.md) for the reproducible
record, render, validation, and publication process. The high-bitrate master
and raw simulation trace are intentionally kept outside public Git history.
