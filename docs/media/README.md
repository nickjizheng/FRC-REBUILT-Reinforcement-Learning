# Documentation media

The main demo is a complete 160-second Stage-D match. It starts at zero,
finishes at 201, uses the exact 456-FUEL field, and combines a slanted field
view with three robot-camera insets and live telemetry.

[![Watch the complete Stage-D score-201 match](frc-rebuilt-score-201-poster.png)](https://github.com/nickjizheng/FRC-REBUILT-Reinforcement-Learning/releases/download/v1.0.0/frc-rebuilt-score-201-full-match-web.mp4)

Supporting public files:

- [`frc-rebuilt-score-201-full-match-web.mp4`](frc-rebuilt-score-201-full-match-web.mp4) — compact, browser-ready H.264 video.
- [`frc-rebuilt-score-201-full-match.mp4`](https://github.com/nickjizheng/FRC-REBUILT-Reinforcement-Learning/releases/download/v1.0.0/frc-rebuilt-score-201-full-match.mp4) — high-quality 1080p H.264 video from the same render.
- [`frc-rebuilt-score-201-poster.png`](frc-rebuilt-score-201-poster.png) — static poster.
- [`score201-public-provenance.json`](score201-public-provenance.json) — sanitized match, checkpoint, and media checksums.

See the [video workflow](../VIDEO_RENDER_WORKFLOW.md) for the reproducible
record, render, validation, and publication process. The high-quality master is
distributed through the v1.0.0 GitHub release; the raw simulation trace remains
outside public Git history.
